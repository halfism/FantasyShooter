# poly.pizza 选中的模型（一行一个，`#` 后是注释）
#
# 挑选标准（都是被截图打脸之后总结出来的）：
#   1. **必须是竖立件**。俯视 55 度下横躺的东西一律被读成"地面斑块"，
#      所以 log / rock_flat / stairs 这类再精致也不用。
#   2. tris 控制在 6k 以内。173 个候选里有 32220 面的"整片树林"，那是组合体，
#      不是单件道具，放进 3000uu 见方的场地会撑爆。
#   3. 尺寸单位不可靠（有的 glb 是毫米，`ruined_building` 报 475180cm），
#      但 AddProp 按目标高度等比缩放，所以只要**长宽高比例**正常就能用。
#      1e7 以上的直接放弃 —— float32 在那个量级的精度只有个位数，缩放后会抖。
#
# 未列出的模型不会被转成 OBJ，也就不进版本库。
